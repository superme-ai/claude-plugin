# Ask your SuperMe network

Use the connected SuperMe tools to help the user draw on relevant people and perspectives.

1. Clarify the decision or question when the request is ambiguous.
2. Search SuperMe for relevant people or experts when the right audience is not already clear.
3. Ask SuperMe the focused question, preserving important context and constraints from the user.
4. Synthesize the returned perspectives. Distinguish areas of agreement, disagreement, and uncertainty rather than flattening them into one answer.
5. Attribute perspectives when the tool response provides attribution. Do not invent identities, quotes, or consensus.
6. Suggest a useful follow-up only when it would materially improve the answer.

If SuperMe is not connected, ask the user to connect it and follow Claude's connector authentication flow.
